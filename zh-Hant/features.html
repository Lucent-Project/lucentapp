功能

不止於記錄

每一項功能都回答同一個問題：這個應用程式，憑什麼值得住進你的手機和電腦？

01 — AI 助手

有意見，更有手

此乃 Lucent 定義性的功能。自帶模型——OpenAI、Anthropic 和 Google 的請求格式皆能從容應對，可儲存多組設定、一鍵切換——或索性在裝置上全本地執行。什麼都不配，助手便不存在；筆記應用程式本身依然完備如初。

使其真正值得擁有的，是它能動手：建立、讀取、編輯、標色、置頂、封存、刪除筆記；建立、完成、重新開啟、排程、設定優先級的任務；用真正的篩選語言進行搜尋；以及附加、重新命名或刪除檔案。一個有意見而無手的東西叫聊天，這是一位被教導先敲門的管家。

在觸動任何資料之前，它會精確地向你展示意圖——用你的語言，在一個本身即是編輯器的對話方塊裡，每一個待定欄位在你確認之前皆可修改。你的回答永遠是終審裁決。

🪞 動手先敲門每次改動都有可視預覽，可逐欄位編輯，點頭之後才執行。
🗂️ 四塊工作面板它記的待辦、它走的計畫、它開的背景工作、它喚的子代理——每一塊都能即時圍觀、叫停、加指示。
🧰 幕後有個工作坊設定裡藏著完整工具箱：讀寫檔案、跑指令、Git、讀網頁、查 SQLite，原生讀寫 Word / Excel / PPT——底層沒有套任何辦公庫。
🧠 三種記憶記住這次對話、記住這個專案、記住你這個人。寫下技能之後，同樣的習慣不用教第二遍。
02 — 模型選擇

雲端、本機，或者不要助手，都行

匯入一個 .gguf 檔案（或內含它的 .zip），助手便藉由直接執行在裝置上的 llama.cpp 作答——無帳號、無 API 金鑰、無網路，你離開應用程式的瞬間模型即被卸載。約 1–4 GB 的 Q4 模型在手機上恰如其分；桌面端則可放手更為大膽。工具函式在本機模式下需手動開啟，GPU 加速在一條直白的警告之後方可選擇：CPU 始終可靠，而 GPU 若意見不合，會優雅地退回。視覺能力亦屬選用——匯入一個 mmproj 檔案，助手便能審視一張照片，並與你討論它。

☁️ 雲端模型多組設定存著，一鍵切換，帳單你自己定。
📲 本機模型llama.cpp 直驅你的晶片，斷網也能用的實在智慧。
03 — 筆記

記得自己前世的筆記

每一次有意義的編輯都被快照留存，你能精確回溯某條筆記曾經的模樣，並在某次信心滿滿的重寫被證明過於冒進時，將它完璧歸趙。輸入 [[購物清單]]，即成為一個可點擊的連結；若所指標題尚不存在，連結會以紅色示警，直到你點擊——筆記便應聲而生。

🕰️ 快照與歷史深夜的重寫，早上總能復原。
🔗 雙向連結[[ ]] 一寫即鏈，紅鏈一點即建，知識自己長成網。
📝 範本空白頁四個一鍵開頭；你自己的範本存下來，每次新增都在門口含笑相迎；長按可編輯或淘汰其中任何一個。
🎨 塗鴉與富文字文字到不了的地方，畫布來。核取方塊是頭等公民，可原地改寫、可彈跳視窗大修。
🏷️ 標籤·顏色·置頂附件逐個加密，還有一方自帶獨立門鎖的私密區域。
🗑️ 草稿與垃圾桶分開未竟之思是草稿，不是垃圾——它值得一個體面的去處。
04 — 任務

真正有意義的截止日期

子任務、優先級、重複週期，以及重啟後依然屹立的提醒。截止日期從自然語言解析——下週五6點變成一枚真實的時間戳記與一聲真實的鬧鐘——重複節奏是一等公民，而非一句終將食言的許諾。完成一項任務，它連帶整條核取方塊一併勾去，已完成的任務自動遷往一個專屬螢幕，各得其所。

🗣️ 自然語言日期「下週五6點」→ 真時間戳記 + 真鬧鐘。
🔁 重複排程重複是一等公民，不是靠小聰明撐起來的句子。
⏰ 提醒重啟不丟，睡一覺醒來它還在。
✅ 清單連動任務完成，子清單全體打勾，一個不留。
05 — 介面

坦蕩磊落，玻璃質感

一道流動的漸層在毛玻璃面板後方悠然漂移，模糊著它下方掠過的一切，幾乎從不重複，以裝置預先應允的代價執行。八個風格系列，豐盛的調色盤，還有自動循環或隨機漫步的陪伴功能。淺色、深色、跟隨系統，以及一系列 Monet 色調的主題——在 Android 12 及以上版本，調色盤會借用你桌布當日的配色方案。小工具將同樣的玻璃質感延伸至你的啟動器；在 Windows 上，應用程式隱入系統匣，側邊欄取代底部標籤頁——因為一面寬闊的螢幕理應得到比手機版面橫向拉伸更優雅的禮遇。

06 — 語言與建置

四種語言，一鍵建置

英語、簡體中文、日本語、한국어——覆蓋每一個螢幕、對話方塊、日期格式與範本。切換語言，整個應用程式在同一畫面播放速率內隨之流轉，因為只有一份翻譯目錄。建置更省事：不用裝 Android Studio，不用敲指令列，在 GitHub 上按一個按鈕，去泡杯茶，回來時安裝套件已安然等候。配方寫在儲存庫裡，不在作者的腦子裡。
