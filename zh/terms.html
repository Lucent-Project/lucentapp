1. 适用范围

本条款适用于面向 Android 和 Windows 的 Lucent 应用（“应用”）以及本网站（“网站”）。Lucent 由 Yuan0-o（“开发者”）开发。下载、安装或使用应用，或使用本网站，即表示你同意这些条款；如不同意，请不要使用。

3. 官方下载

官方构建只发布在本项目的 GitHub Releases 页面，并从本网站链接过去。来自其他渠道的安装包并非开发者提供，可能已被篡改。标记为预发布（pre-release）的版本是供测试的预览版，可能不稳定；标记为“Latest”的才是稳定版。

4. 你的数据，你来负责

Lucent 把你的笔记、任务、附件、设置和密钥加密保存在你自己的设备上。没有 Lucent 账号，也没有 Lucent 服务器（见隐私政策），因此开发者无法读取你的数据，也无法替你找回。

你需要自行负责设备的安全、应用锁密码和备份密码（忘记的密码任何人都无法找回），并保留可用于恢复的备份。导出的文件不会加密。

5. 助手与第三方服务

助手是可选的。如果你连接云端模型、网页搜索、WebDAV 存储、GitHub 或其他任何服务，使用的是你自己的账号和密钥，并由你的设备直接发起连接。这些服务由第三方按其自身的条款和隐私政策运营，可能收费，也可能变更或停止；开发者不是这些服务的一方，也不对其负责。

助手生成的内容可能有误、不完整或已过时，依赖之前请先核对。

6. 由你批准的操作

助手可以创建、编辑和删除笔记、任务与文件；如果你开启了相应的工具和权限，它还能运行命令、使用 Git 或操作你的设备。默认情况下它会先征求你的同意。你需要对自己批准的操作和授予的权限负责：请不要授予你不放心的访问权限，并保留备份。
