功能

不止于记录

每一项功能都回答同一个问题：这个应用，凭什么值得住进你的手机和电脑？

01 — AI 助手

有意见，更有手

此乃 Lucent 定义性的功能。自带模型——OpenAI、Anthropic 和 Google 的请求格式皆能从容应对，可保存多组配置、一键切换——或索性在设备上全本地运行。什么都不配，助手便不存在；笔记应用本身依然完备如初。

使其真正值得拥有的，是它能动手：创建、读取、编辑、标色、置顶、归档、删除笔记；创建、完成、重开、排期、设定优先级的任务；用真正的过滤语言进行搜索；以及附加、重命名或删除文件。一个有意见而无手的东西叫聊天，这是一位被教导先敲门的管家。

在触动任何数据之前，它会精确地向你展示意图——用你的语言，在一个本身即是编辑器的对话框里，每一个待定字段在你确认之前皆可修改。你的回答永远是终审裁决。

🪞 动手先敲门每次改动都有可视预览，可逐字段编辑，点头之后才执行。
🗂️ 四块工作面板它记的待办、它走的计划、它开的后台任务、它唤的子智能体——每一块都能实时围观、叫停、加指示。
🧰 幕后有个车间设置里藏着完整工具箱：读写文件、跑命令、Git、读网页、查 SQLite，原生读写 Word / Excel / PPT——底层没有套任何办公库。
🧠 三种记忆记住这次对话、记住这个项目、记住你这个人。写下技能之后，同样的习惯不用教第二遍。
02 — 模型选择

云端、本机，或者不要助手，都行

导入一个 .gguf 文件（或内含它的 .zip），助手便借由直接运行在设备上的 llama.cpp 作答——无账号、无 API 密钥、无网络，你离开应用的瞬间模型即被卸载。约 1–4 GB 的 Q4 模型在手机上恰如其分；桌面端则可放手更为大胆。工具函数在本地模式下需手动开启，GPU 加速在一条直白的警告之后方可选择：CPU 始终可靠，而 GPU 若意见不合，会优雅地退回。视觉能力亦属可选——导入一个 mmproj 文件，助手便能审视一张照片，并与你讨论它。

☁️ 云端模型多组配置存着，一键切换，账单你自己定。
📲 本机模型llama.cpp 直驱你的芯片，断网也能用的实在智能。
03 — 笔记

记得自己前世的笔记

每一次有意义的编辑都被快照留存，你能精确回溯某条笔记曾经的模样，并在某次信心满满的重写被证明过于冒进时，将它完璧归赵。输入 [[购物清单]]，即成为一个可点击的链接；若所指标题尚不存在，链接会以红色示警，直到你点击——笔记便应声而生。

🕰️ 快照与历史深夜的重写，早上总能撤销。
🔗 双向链接[[ ]] 一写即链，红链一点即建，知识自己长成网。
📝 模板空白页四个一键开头；你自己的模板存下来，每次新建都在门口含笑相迎；长按可编辑或淘汰其中任何一个。
🎨 涂鸦与富文本文字到不了的地方，画布来。复选框是头等公民，可原地改写、可弹窗大修。
🏷️ 标签·颜色·置顶附件逐个加密，还有一方自带独立门锁的私密区域。
🗑️ 草稿与回收站分开未竟之思是草稿，不是垃圾——它值得一个体面的去处。
04 — 任务

真正有意义的截止日期

子任务、优先级、重复周期，以及重启后依然屹立的提醒。截止日期从自然语言解析——下周五6点变成一枚真实的时间戳与一声真实的闹铃——重复节奏是一等公民，而非一句终将食言的许诺。完成一项任务，它连带整条复选框一并勾去，已完成的任务自动迁往一个专属屏幕，各得其所。

🗣️ 自然语言日期"下周五6点"→ 真时间戳 + 真闹铃。
🔁 重复日程重复是一等公民，不是靠小聪明撑起来的句子。
⏰ 提醒重启不丢，睡一觉醒来它还在。
✅ 清单联动任务完成，子清单全体打勾，一个不留。
05 — 界面

坦荡磊落，玻璃质感

一道流动的渐变在毛玻璃面板后方悠然漂移，模糊着它下方掠过的一切，几乎从不重复，以设备预先应允的代价运行。八个风格系列，丰盛的调色板，还有自动循环或随机漫步的陪伴功能。浅色、深色、跟随系统，以及一系列 Monet 色调的主题——在 Android 12 及以上版本，调色板会借用你壁纸当日的配色方案。小部件将同样的玻璃质感延伸至你的启动器；在 Windows 上，应用隐入系统托盘，侧边栏取代底部标签栏——因为一面宽阔的显示器理应得到比手机布局横向拉伸更优雅的礼遇。

06 — 语言与构建

四种语言，一键构建

英语、简体中文、日本語、한국어——覆盖每一个屏幕、对话框、日期格式与模板。切换语言，整个应用在同一帧内随之流转，因为只有一份翻译目录。构建更省事：不用装 Android Studio，不用敲命令行，在 GitHub 上按一个按钮，去泡杯茶，回来时安装包已安然等候。配方写在仓库里，不在作者的脑子里。
