Termini di utilizzo

La versione breve e umana delle regole. Lucent è software libero; questi termini spiegano cosa puoi aspettarti — e cosa rimane sotto la tua responsabilità.

Ultimo aggiornamento: 17 ottobre 2026

1. Ambito di applicazione dei termini

Questi termini si applicano all'applicazione Lucent per Android e Windows (l'«App») e a questo sito web (il «Sito»). Lucent è sviluppata da Jessica Martinez (la «sviluppatrice»). Scaricando, installando o utilizzando l'App, oppure utilizzando il Sito, accetti questi termini. Se non sei d'accordo, ti preghiamo di non utilizzarli.

2. Licenza

Il codice sorgente di Lucent è rilasciato con Licenza MIT. Il file LICENSE nel repository è il testo facente fede: finché la nota di copyright e il testo della licenza accompagnano qualsiasi copia o parte sostanziale del codice, puoi utilizzarlo, copiarlo, modificarlo, integrarlo, pubblicarlo, distribuirlo, concederlo in sublicenza e venderlo. I componenti di terze parti mantengono le proprie licenze; consulta il file delle comunicazioni di terze parti nel repository.

3. Download ufficiali

Le build ufficiali sono pubblicate SOLO sulla pagina GitHub Releases del progetto. Questo Sito fornisce un mirror di download ad alta velocità SOLO per l'ULTIMA build STABILE. Le build di anteprima (pre-release) sono destinate ai test e possono essere instabili. Solo il rilascio contrassegnato come "Latest" è la versione stabile. Le build provenienti da qualsiasi altra fonte non provengono dalla sviluppatrice e potrebbero essere state alterate.

4. I tuoi dati, la tua responsabilità

Lucent conserva le tue note, attività, allegati, impostazioni e chiavi sul tuo dispositivo, crittografati. Non esiste alcun account Lucent né alcun server Lucent (vedi l'Informativa sulla privacy), quindi la sviluppatrice non può leggere i tuoi dati né recuperarli per te.

Sei responsabile della sicurezza del tuo dispositivo, della password di blocco dell'app e della password di backup (una password dimenticata non può essere recuperata da nessuno), nonché della conservazione di backup da cui poter effettuare un ripristino. I file esportati non sono crittografati.

5. L'assistente e i servizi di terze parti

L'assistente è facoltativo. Se colleghi un modello cloud, la ricerca web, uno spazio di archiviazione WebDAV, GitHub o qualsiasi altro servizio, lo fai con i tuoi account e le tue chiavi, direttamente dal tuo dispositivo. Tali servizi sono gestiti da terzi in base ai loro termini e informative sulla privacy, possono essere a pagamento e possono cambiare o smettere di funzionare; la sviluppatrice non ne è parte e non ne è responsabile.

Ciò che l'assistente scrive può essere errato, incompleto o non aggiornato. Verificalo prima di farvi affidamento.

6. Azioni approvate dall'utente

L'assistente può creare, modificare ed eliminare note, attività e file — e, se attivi i relativi strumenti e autorizzazioni, eseguire comandi, usare Git o gestire il dispositivo. Per impostazione predefinita ti chiede prima conferma. Sei responsabile di ciò che approvi e delle autorizzazioni concesse: non concedere accessi con cui non ti senti a tuo agio e conserva sempre dei backup.

Utilizza Lucent e il Sito in modo conforme alla legge. Non usare l'App per violare i diritti altrui o i termini dei servizi a cui la colleghi, non tentare di interrompere, sondare o sovraccaricare il Sito o l'infrastruttura GitHub del progetto e non spacciare build modificate per ufficiali.
