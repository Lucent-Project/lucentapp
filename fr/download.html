Android

Un APK signé — Kotlin et Jetpack Compose, Room sur SQLCipher, llama.cpp via le NDK. Widgets pour l'écran d'accueil inclus, naturellement.

Windows

Un programme d'installation .exe à double-clic — Compose for Desktop sur une JVM pure, SQLite via JDBC, llama.cpp sous forme de DLL. Résident dans la barre des tâches, avec une barre latérale taillée pour les écrans larges.
